## 협업 원칙

1. 매주 목요일 수업 시간 내 팀 미팅에서 각자 진행상황 공유 (Weekly Report 양식 사용)
2. 팀원별 작업은 세부 단위로 쪼개어 배정하고, 마감일을 팀 전체 일정보다 며칠 앞당겨 설정하여 지연에 대비한다
3. 카카오톡/깃허브 이슈로 작업 요청 및 진행상황 기록
4. 팀원이 기한 내 산출물을 제출하지 않을 경우, 팀장이 직접 해당 작업을 이어받아 완료한다
5. 개인 기여도는 깃허브 커밋 이력과 회의록 기준으로 기록하여 개인 기여일지 작성 시 활용
